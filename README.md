# Limacina Launcher

Лаунчер Minecraft **Limacina** построен на Tauri 2 (Rust + Vue 3). Он устанавливает игру и Java, поддерживает моды и загрузчики, управляет скинами и моделями игроков и умеет работать в паре с сервером лаунчера `limacina`: приватный сервер получает собственную авторизацию, синхронизацию файлов и контент игроков.

Лаунчер работает в двух режимах:

- **Серверный профиль**: подключение к приватному серверу Limacina с собственной авторизацией, автоматической синхронизацией файлов и модов, скинами и моделями игроков.
- **Одиночный профиль**: самостоятельная игра по нику в одиночном мире или на обычных серверах, сервер лаунчера не нужен.

## С чем работает

| Что | Поддержка |
|---|---|
| Minecraft | версии от 1.13 и выше, доступны релизы и снапшоты |
| Загрузчики | Vanilla (без загрузчика), Fabric, Forge, NeoForge |
| Java | автоматическая загрузка нужной версии (Adoptium), альтернативные дистрибутивы (Foojay) или свой путь до JDK |
| Платформы | Windows (установщик NSIS) и Linux (сборка из исходников), поддержка macOS запланирована |
| Моды | каталог Modrinth и моды с сервера лаунчера |

## Возможности

### Профили и аккаунты
- Несколько игровых профилей: у каждого своя версия Minecraft, загрузчик и независимые файлы.
- Мультиаккаунтность: несколько аккаунтов в рамках проекта и быстрое переключение между ними.
- Автоматическое восстановление сессий по сохранённым токенам обновления (refresh). Учётные данные хранятся в системном хранилище (Windows Credential Manager или Secret Service). Резервное хранилище на диске записывает только токены, поэтому пароли не сохраняются.

### Запуск игры
- Установка Minecraft и загрузчиков в один клик, с пошаговым прогрессом и обработкой сбоев.
- Настройка запуска: объём памяти, аргументы JVM вручную или готовыми пресетами оптимизации (G1GC, SerialGC для слабых ПК, ZGC).
- Автоматический вход на сервер при запуске (Quick Play для 1.20.3+).
- Проверка целостности файлов с автоматическим восстановлением повреждённых.
- Ограничение скорости загрузки, системные уведомления о завершении установки и запуска, сворачивание в трей с индикацией запущенной игры, Discord Rich Presence.

### Моды
- Встроенный каталог Modrinth: поиск по категориям и сортировкам, установка и удаление в один клик, проверка обновлений установленных модов.
- Синхронизация модов и файлов клиента с сервером лаунчера: файлы проверяются по хешам SHA1, докачиваются только изменённые.
- Кнопка открытия папки mods.

### Скины
- 3D-просмотр скина с зумом, поворотом и полноэкранным режимом. Поддерживаются классическая модель и модель slim, а также старый формат скинов 64×32.
- Загрузка скина на сервер для серверных профилей: скин применяется к аккаунту.
- Скины в одиночном профиле: лаунчер запускает локальный сервер скинов на базе `authlib-injector`, поэтому скин виден в игре даже без лицензионного аккаунта.

### Модели игроков (Custom Player Models)
- 3D-просмотр моделей в формате `.cpmmodel` с воспроизведением анимаций.
- Загрузка модели на сервер, чтобы её увидели другие игроки проекта, или локальная установка в папку `player_models`.

### Интерфейс лаунчера
- Десять тем оформления: пять базовых тем, каждая в тёмном и светлом исполнении. Анимации можно отключить.
- Автообновление лаунчера с проверкой подписи артефактов, откат или переход на конкретную версию.
- Консоль отладки с логами фронтенда и бэкенда.

## Серверная часть

Сервер лаунчера (отдельный проект `limacina`) отвечает за собственную авторизацию с регистрацией, обновление и синхронизацию файлов клиента, раздачу модов, хранение скинов и моделей игроков, а также формирует манифест автообновления лаунчера.

## Стек

Tauri 2 (бэкенд на Rust), Vue 3 + TypeScript + Pinia, Three.js для трёхмерного просмотра скинов и моделей, тесты на Vitest и cargo test.

## Сборка

Требуется: [bun](https://bun.sh), Rust toolchain, системные зависимости Tauri (в Linux это `libwebkit2gtk-4.1-dev` и другие, см. [tauri docs](https://tauri.app/start/prerequisites/)).

```bash
# 1. Конфиг окружения (gitignored)
cp src-tauri/.env.example src-tauri/.env
# LAUNCHER_NAME: имя папки и приложения, LAUNCHER_SERVER_URL: адрес сервера лаунчера,
# DISCORD_CLIENT_ID: Discord Application ID (если пусто, Rich Presence отключён)

# 2. Зависимости
bun install

# 3. Разработка (Vite dev server + Rust)
bunx tauri dev

# 4. Релизная сборка (фронтенд и бинарник под текущую ОС)
bunx tauri build
```

> `.env` встраивается в бинарник на этапе компиляции через `include_str!` в `lib.rs`. При изменении значений cargo пересобирает crate автоматически, поэтому `cargo clean` не нужен.
